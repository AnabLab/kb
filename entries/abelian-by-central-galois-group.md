**Pro-$\ell$ form.** Fix a prime $\ell$. For a field $K$ of characteristic different from $\ell$, let $G_K = \mathrm{Gal}(K(\ell)|K)$ be the maximal pro-$\ell$ Galois group. Put

$$\Pi^a_K = G_K/[G_K,G_K], \qquad \Pi^c_K = G_K/[G_K,[G_K,G_K]].$$

The map $\Pi^c_K \to \Pi^a_K$ is a central extension, with kernel $\Delta_K$. For $\sigma, \tau \in \Pi^a_K$, the commutator of any lifts to $\Pi^c_K$ is an element $[\sigma,\tau] \in \Delta_K$ independent of the lifts, and this defines a $\mathbb{Z}_\ell$-bilinear pairing. An isomorphism $\varphi : \Pi^a_L \to \Pi^a_K$ is compatible with the pairing if there is an isomorphism $\psi : \Delta_L \to \Delta_K$ with $\psi[\sigma,\tau] = [\varphi\sigma, \varphi\tau]$ for all $\sigma, \tau$ [@topaz2016, §1].

**Kummer duality.** Suppose $K$ is a function field over an algebraically closed field $k$. After fixing an isomorphism $\mathbb{Z}_\ell(1) \cong \mathbb{Z}_\ell$, Kummer theory identifies $\mathrm{Hom}(\Pi^a_K, \mathbb{Z}_\ell)$ with the $\ell$-adic completion of $K^\times$, whose completion map has kernel $k^\times$ [@topaz2016, §1.1].

**Mod-$\ell$ form.** For a pro-$\ell$ group $G$, put $G^{(2)} = [G,G] \cdot G^\ell$. Put $G^{(3)} = [G,G^{(2)}] \cdot G^\ell$ if $\ell \ne 2$, and $G^{(3)} = [G,G^{(2)}] \cdot (G^{(2)})^\ell$ if $\ell = 2$. Then $G^a = G/G^{(2)}$ and $G^c = G/G^{(3)}$, and $G^c \to G^a$ is a central extension with kernel $Z_K$. Commutators of lifts define a $\mathbb{Z}/\ell$-bilinear pairing on $G^a_K$. Let $Z^0_K \subseteq Z_K$ be the closed subgroup generated by its values, which can be proper only if $\ell = 2$. An isomorphism $\varphi : G^a_L \to G^a_K$ is compatible with the pairing if there is an isomorphism $\psi : Z^0_L \to Z^0_K$ with $\psi[\sigma,\tau] = [\varphi\sigma, \varphi\tau]$ [@topaz2016, §1.2]. For a function field over an algebraically closed field of characteristic different from $\ell$, Kummer theory identifies $\mathrm{Hom}(G^a_K, \mathbb{Z}/\ell)$ with $K^\times/\ell$ [@topaz2016, §1.3].

**Notation.** The group $\Pi^c_K$ is the largest pro-$\ell$ quotient of nilpotency class at most $2$, which [@koymanspagano2024, §1.2] writes $G_K^2(\ell)$. Elsewhere in this knowledgebase, $G_K^2$ means the [metabelian quotient](m-step-solvable-quotient.md).
